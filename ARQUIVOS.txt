P: Por onde começo?
R: Leia QUICKSTART.md (5 minutos), depois execute os 3 passos.

P: Qual arquivo é mais importante?
R: app.py (aplicação) e Churn_Modelling.csv (dados) são essenciais.
   Os demais são documentação (muito recomendada).

P: Preciso modificar algo?
R: Não! A aplicação funciona como está. Customize se desejar (veja QUICKSTART.md).

P: Como faço deploy?
R: Siga DEPLOYMENT.md. Recomendo Streamlit Cloud (gratuito e fácil).

P: Posso usar meus próprios dados?
R: Sim! Substitua Churn_Modelling.csv por seus dados (mesma estrutura).

P: Os dados são reais?
R: São de exemplo (Kaggle). Você pode usar seus dados reais.

P: Quanto tempo leva para rodar?
R: Primeira vez: ~2-3 minutos (treinamento)
   Depois: <1 segundo (cache automático)

P: Posso compartilhar com meu time?
R: Sim! Deploy em Streamlit Cloud gera URL pública.

P: Preciso de GPU?
R: Não. CPU é suficiente (os dados são pequenos).
